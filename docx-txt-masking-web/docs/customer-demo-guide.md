# 客户演示指南

1. 使用 Node.js 22 LTS。不要在 Windows 与 WSL 之间复用同一个 `node_modules`。
2. 启动后端和前端。
3. 打开 `http://localhost:3000`。
4. 上传由 `scripts/generate-sample-data.py` 生成的 DOCX 测试样本。
5. 填写分类编码、分类名称、分级标签和备注。
6. 点击“上传并创建任务”。
7. 在清单查看实体数量、处理数量、处理状态和复检状态。
8. 打开详情页查看原文预览和脱敏后预览。
9. 下载 DOCX，用 Word 打开确认文件可用。
10. 上传 TXT 重复验证，确认 TXT 输出没有系统强制写入的 metadata header。
11. 点击“导出 CSV”确认清单可导出。
12. 点击“下载 ZIP”确认包含 `处理清单.csv` 和 `脱敏文件/`。
13. 删除任务，确认清单记录消失且后端本地文件同步删除。
14. 上传无身份证文件，确认状态为“未发现敏感实体”，复检为“未通过”。

当前本机 Windows 前端运行环境阻塞；客户演示应等待 Ubuntu CI 前端构建和 Playwright 端到端验收通过后执行。
